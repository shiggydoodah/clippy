# Clippy

`⌘V`, but with a memory. 📎

## About

Clippy is a small menu bar app that remembers what you've copied and lets you get any of it back.

Hit `⌥Space` and a Spotlight-style panel appears with your recent clipboard history. Type to search it, arrow up and down, press `↵` to copy something back. Anything you want to keep for good goes in Favourites, which never get pruned.

It handles text, links, images and files. It skips anything copied from a password manager. And it's entirely local — a SQLite file on your Mac, no account, no sync, and no network connections at all.

No dock icon. Look for the paperclip in your menu bar.

## How to use

Press `⌥Space` anywhere to open the panel, and `⌥Space` or `Esc` to dismiss it. The panel doesn't steal focus, so whatever you were working in stays active.

| Key       | What it does                                       |
| --------- | -------------------------------------------------- |
| `⌥Space`  | Open / close the panel                             |
| `↑` `↓`   | Move through the list                              |
| `↵`       | Copy the selected item                             |
| `⌘↵`      | Copy it and paste it into the app you were just in |
| `⌘1`–`⌘9` | Copy the item at that position                     |
| `Tab`     | Switch between History and Favourites              |
| `⌘F`      | Favourite / unfavourite the selected item          |
| `⌘⌫`      | Delete the selected item (see Favourites)          |
| `⌘⇧V`     | Open it — links in your browser, files in Finder   |
| `⌘↑` `⌘↓` | Reorder favourites (Favourites tab only)           |
| `⌘,`      | Settings                                           |

Just start typing to filter the list.

`⌘↵` needs Accessibility permission, because pasting means synthesising a `⌘V` keystroke. The app asks the first time you use it, and there's a button in Settings → General. If you'd rather not grant it, everything else still works — you just press `⌘V` yourself.

Settings (`⌘,`) is where you change the summon shortcut, turn on launch at login, set how many items to keep and for how long, pick which apps, folders and file extensions never get captured, and manage your favourites. There's also a Danger Zone for clearing everything, which asks first.

## Favourites

Press `⌘F` to keep something for good — favourites are never pruned by your history limits, and you can right-click one to rename it.

A favourite is only ever deleted from the Favourites tab. Pressing `⌘⌫` on one in History takes it out of history and leaves the favourite alone; copying the same thing again brings it back into history. If you then unfavourite it, it's in neither list, so it's gone for good.

Clearing your history from the Danger Zone works the same way: the History list is emptied completely, favourites included, and your favourites stay in Favourites.

## Privacy

A clipboard manager sees everything you copy, so it's worth being specific.

Anything marked as sensitive using the [nspasteboard.org](http://nspasteboard.org) conventions — `ConcealedType`, `TransientType`, `AutoGeneratedType` — is dropped before it reaches any storage path, and isn't logged either. Password managers use these. Copies from known password manager apps are skipped by bundle ID as well, which is on by default.

Everything else lives in `~/Library/Application Support/Clip/` and goes nowhere else. There's no networking code in the app at all: no analytics, no crash reporting, no update check. You can also turn capture off from the menu bar, or run in a mode where history only lives in memory and is gone when you quit.

Two things to know before you trust it with anything sensitive:

- The database uses default file permissions, so other accounts on the same Mac can read it. Fine if it's your machine alone, worth knowing if it isn't.
- The app is **not sandboxed**. It can't be and still do its job — reading the pasteboard other apps write to, and pasting back into the app you were last in, both need it.

## Installing

There's no packaged download — you build it yourself. It takes a couple of minutes and you only do it once.

**You'll need:** macOS 14 (Sonoma) or newer and [Xcode](https://apps.apple.com/gb/app/xcode/id497799835) from the App Store.

**1. Point your Mac at Xcode** (first time only):

```sh
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

**2. Clone and build:**

```sh
git clone https://github.com/shiggydoodah/clippy.git
cd clippy
xcodebuild -project Clippy.xcodeproj -scheme Clippy -configuration Release -derivedDataPath build
```

The first build pulls the two dependencies ([GRDB](https://github.com/groue/GRDB.swift) and [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts)), so give it a minute. You're looking for `** BUILD SUCCEEDED **`.

**3. Move it to Applications:**

```sh
cp -R build/Build/Products/Release/Clippy.app /Applications/
```

**4. Open it.** Because it isn't signed with a paid developer certificate, macOS will block it the first time. Right-click the app, choose Open, and confirm — once only. If that doesn't work, System Settings → Privacy & Security will have an "Open Anyway" button after your first attempt.

**5. Optional — start it at login:** Settings → General → Launch at login.
